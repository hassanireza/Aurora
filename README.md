# Aurora

Shape the cascade. Solve 1,000 CSS puzzles in a warm editorial design studio.

Warm editorial paper, amber gradients, soft coral and fine typographic rules.

## Includes

- 1,000 puzzle records across 50 chapters
- Mobile-first editor, progress map, local progress, hint and answer checking
- Separate free-play terminal and separate test terminal panel
- GitHub Pages workflow for `hassanireza/aurora`

## Runtime notes

This static GitHub Pages game has no server. CSS is checked in a live iframe preview and by authored target comparison.

## Local development

`npm ci` then `npm run dev`. Build with `npm run build`. The Pages workflow deploys the built `dist` directory from the `main` branch.
